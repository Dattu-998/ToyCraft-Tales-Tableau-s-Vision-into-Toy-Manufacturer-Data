# ToyCraft Tales: Tableau's Vision into Toy Manufacturer Data

## Project Overview
ToyCraft Tales leverages Tableau and SQL to analyze the US Toy Manufacturing industry from 2005 to 2016. The project uncovers market trends, production patterns, and regional growth to provide actionable insights for strategic decision-making.

## 🚀 Deliverables & Features
- **Interactive Tableau Dashboard:** Visualizing manufacturer density and YoY growth.
- **SQL Integration:** Systematic data storage and extraction for performance.
- **Flask Web Integration:** Embedding the dashboard into a custom UI for web access.
- **Trend Analysis:** Seasonal and demographic consumer preference insights.

## 📊 Visualizations & Insights
### 1. Market Trend Analysis
Explores the evolution of toy manufacturing over a 12-year period, identifying cycles in industry growth.


### 2. Geographic Distribution
A map-based visualization showing the concentration of manufacturers across the United States, highlighting key hubs like California and New York.


### 3. Regional Performance
Bar charts comparing state-level data to identify which regions are most competitive in the toy sector.

## 🛠️ Tech Stack
- **Data Visualization:** Tableau Desktop
- **Database:** SQL (MySQL/PostgreSQL)
- **Backend:** Python (Flask)
- **Frontend:** HTML/CSS (for Dashboard Embedding)
